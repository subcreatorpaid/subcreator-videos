## PATTERNS ACROSS ALL 15
1. Background: off-white #F4F4F4-ish, faint dotted/plus grid, coral accent only in sunbursts/mascot/stickers. One accent colour, everything else black/grey.
2. Every video opens with motion in frame 0 (grid close-up pull-back, full-bleed screenshot pull-back, object drop) and the hook text builds word-by-word grey->black.
3. Hook formula: setup line small -> NAME/NUMBER huge -> black highlight box (wipe) with the payoff ("While You Sleep", "YES-MAN", "you need right now", "free & opensource").
4. Visual changes every 2-4 s; text on screen is max ~8 words; the voice and the words are in sync.
5. Body template: text top, visual middle (screenshot card / phone / laptop / icon), caption bottom, ✦ bullets build one per phrase.
6. Item intro: "First is" + logo badge pill or uppercase name + product card.
7. Diagrams instead of footage: node timelines, fan-out lines, orbit rings, dotted step paths, connector lines with dot ends.
8. Proof: stat cards (stars/forks), stacked pricing cards, showcase walls of outputs, big numbers.
9. Emotion props: mascot (with ! / ? / tag), stickers, halftone hands, real-object cut-outs as analogies.
10. Transitions: punch zoom, blur-whip, SHATTER (glass break), motion streak, slide-in from frame edge, rack focus (blur->sharp).
11. Retention devices: early "Save this" bookmark beat (~5-7 s), recap "You just found N tools that most X don't know" + highlight box before the CTA.
12. Same CTA every time: Comment "WORD" -> tilted book drops -> pages fan/spread full screen -> promise line -> follow logo bounce + "the system only sends it to FOLLOWERS".
