# Goal lock

## Locked goal
**10,000 followers across Instagram and TikTok in 90 days** (set 2026-10-23). The owner can change it by saying "new goal lock: ...". Repeat the current goal at the top of every check.

## Input
One idea, trend, topic, collab or plan, in any form.

## The five tests
1. **Under-10k fit** - does it help creators with 0 to 10,000 followers? Advice that only works for big accounts fails.
2. **Send-able** - would a viewer send it to a creator friend? Sends drive reach to non-followers.
3. **Core belief** - does it show a way to earn before 10k?
4. **Verifiable** - can every claim be backed by a current source?
5. **On brand** - professional, specific, honest; nothing from the never list (no "hack", "quit your job", "bro", emojis on screen, bashing creators, promised earnings).

## Output (exactly this shape, short)
```
GOAL: 10k followers on IG + TikTok by [date]
IDEA: <one line>
VERDICT: On goal | One fix away | Off goal
TESTS: fit ✓/✗ · send-able ✓/✗ · core belief ✓/✗ · verifiable ✓/✗ · on brand ✓/✗
WHY: <two sentences max>
FIX: <the one change that makes it on goal, or "none needed">
SUGGESTED HOOK: <one line in brand voice, if on goal or after the fix>
```

## Rules
- Views alone are not the goal; a viral video that attracts the wrong audience is Off goal.
- Trending topics pass only if all five tests pass after the fix.
- Never soften a verdict to please. Be direct and brief.
