# Run log (one file per entry)

Each run writes its own file here so pull requests never edit the same file (no merge conflicts).
Name: `YYYY-MM-DD-HHMM-<role>-<slug>.md`. Content: ONE line, `YYYY-MM-DD HH:MM | role | what was done | what needs the owner`.
Older entries are in `brain/log.md` (frozen history, do not edit). The dashboard and secretary read both.
